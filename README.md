# iotDASHBOARDjuanS

Qué hace
La aplicación es un tablero web interactivo que procesa registros de salud simulados de un tótem universitario (sensor MAX30102 y NFC). Convierte datos crudos de un archivo CSV en visualizaciones analíticas y permite chatear directamente con una inteligencia artificial usando una clave de OpenAI propia.

Funciones principales

Filtros globales: Segmenta la información por fechas, estado de lectura y estudiantes específicos en tiempo real.

Métricas y gráficos: Muestra indicadores clave (totales, promedios de ritmo cardíaco y oxígeno) junto con mapas de calor de afluencia y diagramas de calidad de señal.

Seguimiento individual: Audita el historial clínico-experimental de cualquier estudiante seleccionado.

Copiloto integrado: Analiza contexto estadístico local para responder consultas y resolver dudas técnicas mediante un chat en pantalla.

Valor para el usuario

Estudiantes: Facilita la exploración de los datos del proyecto y sirve como herramienta de apoyo visual durante la sustentación académica.

Evaluadores: Cumple con los requerimientos del curso integrando procesamiento de datos y diseño web funcional.
